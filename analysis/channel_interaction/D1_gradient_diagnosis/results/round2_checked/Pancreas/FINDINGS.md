rho=||gL+gU||/(||gL||+||gU||)，越小表示抵消越强；抵消程度为 1-rho。raw 使用原目标中的 U 权重 .3，effective 使用整体四头目标 LossNorm。两裁块先归一化再平均所产生的 L/U 余弦均值最大差为 0.154。同观测正标量缩放保留余弦，但会改变幅值平衡及抵消；病例平均向量会受重加权影响。完整范数与 U/L 比例在 observation_norms.csv、mini_relations.csv。

## 验证、局限和继续条件

统一数值策略：FP32 首测触发原重构阈值时，恢复 BN/RNG 并以 FP64 重放整个 L/U 单元，仍通过原严格检查。此数据集有 3 个单元触发重放，正式保存的 6 个观测使用 FP64；其余为 FP32。触发原因与失败尝试的状态恢复见 restoration_checks.json。该策略不依据余弦符号或数据集效果，不修改公式或阈值。

原始/有效梯度重构最大 relative L2 为 1.974e-06/6.926e-04；214 个可达逐观测通道因零值/过小而无效，已排除余弦。BN、RNG、参数、模式、grad 均恢复；train 首组重放误差为 0；U GT 读取和 optimizer step 均为 0。

沿用原 checker：仅在绝对 L2 误差 >1e-9 且相对 L2 >1e-4 时拒绝。Pancreas 有两条极小 U 梯度的相对误差超过 1e-4，但最大系数误差仅约 1.9e-12 / 3.2e-12，且对应的原始 D1 十六通道全部低于有效性阈值；未将它们当作可靠逐裁块方向。详见 [数值边缘记录](../../../NUMERICAL_EDGE_CASES.md)。

仅单 checkpoint、单划分、16 个 U、每病例两裁块。mini-batch 只含三个病例组，未分离 BN 与 Dropout；LA mini 使用 6/8 个 L。部分单元的 FP64 重放会引入微小舍入差异，mode_comparison.csv 同时记录两侧精度。原 test.list 已用于 Baseline 在线选模，不能称为独立验证集。没有训练性能或干预终点，没有多重比较校正。

**负余弦不能解释为有害通道。**它描述当前两个目标在共享参数坐标上的方向差异，不能证明删除/交换会改善性能，也不能证明协同、互补或边界语义。满足继续扩大冻结诊断的工程条件；本轮证据不足以据此固定通道筛选、开始 POS 或通道交换。
